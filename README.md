# 备忘录 · dsh-better-memo

给 DeepSeek Harness 加一层**三层备忘录**：顶栏一个小胶囊，点开是浮窗卡片，一条一条列出来，**点一条就复制**。同一个面板里管三档归属，其中两档 AI 能读能改，第三档只有你自己看得到（AI 只有在你逐次批准之后才能读一次）。

| 作用域 | 谁收得到 | AI 能看 | AI 能写 |
|---|---|---|---|
| **本会话** `session` | 只有这一个会话 | ✅ | ✅ |
| **全局共享** `profile` | 这个 profile 的所有会话 | ✅ | ✅ |
| **仅用户** `user` | 只有你自己 | ❌ 默认永远不返回；只能**申请**读，每次都要你批准 | ❌ 只有你能写 |

## 安装

```bash
dsh plugin --profile <你的 profile> add dsh-better-memo
```

装完**重启该 profile 的 GUI**（浏览器半段与 locale 元数据都是启动时读的）。

## 用

1. **顶栏胶囊**（窗口右上角，`备忘录`）：点一下弹出浮窗卡片。
2. **浮窗卡片**：一条一条，左边彩色圆点区分三档（蓝=本会话 / 绿=全局共享 / 黄=仅用户）。**点一条 = 复制到剪贴板**（格式 `标题\n正文`），右下角浮出「已复制」。点卡片外面、按 ESC、或再点胶囊都能关。
3. **齿轮 → 设置页**：卡片右上角的齿轮点进去是整页模式，可以做全部管理（新增、勾完成、行内改、两次确认删），顶部有开关 **「在会话 tab 行显示「备忘录」入口」**，**默认关**。打开后会话 tab 行才出现「备忘录」座位，关掉立刻消失，不用重启。

## 给 AI 的五个工具

**一个工具只对应一档**，档位由工具本身固定，schema 里**没有 `scope` 字段** —— AI 选错档是 0.2.x 的实际故障来源。读工具还会按需出现：那一档没有条目时，工具连声明都不下发给模型。

| 工具 | 读/写 | 归属 | 什么时候暴露给 AI |
|---|---|---|---|
| **`memo_list`** | 读 | `session`（本会话） | **仅当本会话确有 `session` 条目时**；只返回这一档，已勾完成的过滤掉 |
| **`memo_list_shared`** | 读 | `profile`（全局共享） | **仅当 `profile` 档非空时**；只返回这一档 |
| **`memo_edit`** | 写 | `session`（本会话） | 恒可用（否则第一条永远写不出来）；`add` 只写 `session`，`update`/`delete` 只能动本会话的条目 |
| **`memo_edit_shared`** | 写 | `profile`（全局共享） | 恒可用；写入的条目 `scope` 恒为 `profile`，只能动共享档的条目 |
| **`memo_read_private`** | 读 | `user`（仅用户） | **仅当 `user` 档非空、且宿主的批准服务可用时**；每次调用都要用户当场批准 |

- 写工具：`op=add|update|delete`。`add` 要 title 或 body；`update`/`delete` 要 `id`（读工具返回的那个），`update` 除 title/body 外还能改 `done`（勾完成 / 取消勾）。越档、跨会话、动 `user` 条目一律返回 `{ ok:false, error:… }`。条目都记来源会话 `sessionId`（写 `profile` 时也记），方便区分是谁记的。
- **读仅用户可见要每次批准**：`memo_read_private` 走宿主自带的批准面板，批准是**一次性**的，下一次调用要重新问，不做永久授权。**被拒 / 取消 / 没有批准服务时什么也不返回** —— 不返回条目、不返回标题、连条数都不给，只有 `{ ok:false, error:'user denied' | 'cancelled' | 'approval unavailable' }`。批准通过才返回标题 + 正文 + id + 时间。

会话开始时若用户提到「备忘录 / 备忘 / 记一下 / 待办」，AI 会先调对应档的读工具（插件自带这段系统提示，一般不用再写）。

## 数据放哪

`$DSH_HOME/memo/memos.json`（`DSH_HOME` 缺省 `~/.dsh`），一个 JSON 文件，原子写。删掉它等于清空全部备忘录。

条目上限 500 条；标题 120 字、正文 4000 字（超出截断）。插件自己的开关（`showTabEntry`）也在这个文件的 `settings` 里。

## 已知限制

- **复制依赖窗口焦点**：用的是 `navigator.clipboard.writeText`，失败时退回 `document.execCommand('copy')`；两个都失败会明确显示「复制失败」，不会假装成功。窗口失焦的后台环境两个都会失败（这是浏览器的规矩，不是插件 bug）。
- 顶栏胶囊与同一行图标按钮同高同圆角（高 28、圆角 8、`top:11px; right:150px`）。**只在真正打开了一个会话时才显示**：欢迎页 / 新会话尚未进入对话时没有这个按钮。如果没有 `shell.overlay` 槽（个别环境），入口会退化成右下角的固定圆钮。
- 单机单文件，没有多端同步；全局共享档只在本 profile 内共享。
- **读「仅用户」只在会话进行中可申请**：批准走宿主自带的批准服务，必须在模型这一轮还开着的时候问，轮次之间没有可问的通道。宿主没有批准服务（headless / 没装 answerer）时这个工具根本不注册，不会退化成「默认可读」。
- **批准没有永久授权**：批准一次只对那一次调用有效，下一次调用重新问；被拒后 AI 拿到的是一个纯错误对象，里面没有任何条目内容，也没有条数。
- 没有提醒/定时：这不是提醒插件，是备忘录。

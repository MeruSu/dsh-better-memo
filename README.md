# 备忘录 · dsh-better-memo

给 DeepSeek Harness 加一层**三层备忘录**：顶栏一个小胶囊，点开是浮窗卡片，一条一条列出来，**点一条就复制**。同一个面板里管三档归属，其中两档 AI 能读能改，第三档只有你自己看得到。

| 作用域 | 谁收得到 | AI 能看 | AI 能写 |
|---|---|---|---|
| **本会话** `session` | 只有这一个会话 | ✅ | ✅ |
| **本 profile** `profile` | 这个 profile 的所有会话 | ✅ | ✅ |
| **仅我可见** `user` | 只有你自己 | ❌ 永远不返回 | ❌ 只有你能写 |

## 安装

```bash
dsh plugin --profile <你的 profile> add dsh-better-memo
```

装完**重启该 profile 的 GUI**（浏览器半段与 locale 元数据都是启动时读的）。

## 用

1. **顶栏胶囊**（窗口右上角，`备忘录`）：点一下弹出浮窗卡片。
2. **浮窗卡片**：一条一条，左边彩色圆点区分三档（蓝=本会话 / 绿=本 profile / 黄=仅我可见）。**点一条 = 复制到剪贴板**（格式 `标题\n正文`），右下角浮出「已复制」。点卡片外面、按 ESC、或再点胶囊都能关。
3. **齿轮 → 设置页**：卡片右上角的齿轮点进去是整页模式，可以做全部管理（新增、勾完成、行内改、两次确认删），顶部有开关 **「在会话 tab 行显示「备忘录」入口」**，**默认关**。打开后会话 tab 行才出现「备忘录」座位，关掉立刻消失，不用重启。

## 给 AI 的两个工具

- **`memo_list`** —— 返回本会话该查收的条目：本会话的 `session` + 本 profile 的 `profile`，已勾完成的会过滤掉。**`仅我可见` 的条目永远不会出现在这里。**
- **`memo_edit`** —— `op=add|update|delete`。`add` 必须给 `scope`（`session` 或 `profile`）；`update`/`delete` 要 `id`。只能改自己看得到的条目，跨会话或 `user` 条目会被拒。

会话开始时若用户提到「备忘录 / 备忘 / 记一下 / 待办」，会先调 `memo_list`（插件自带这段系统提示，一般不用再写）。

## 数据放哪

`$DSH_HOME/memo/memos.json`（`DSH_HOME` 缺省 `~/.dsh`），一个 JSON 文件，原子写。删掉它等于清空全部备忘录。

条目上限 500 条；标题 120 字、正文 4000 字（超出截断）。插件自己的开关（`showTabEntry`）也在这个文件的 `settings` 里。

## 已知限制

- **复制依赖窗口焦点**：用的是 `navigator.clipboard.writeText`，失败时退回 `document.execCommand('copy')`；两个都失败会明确显示「复制失败」，不会假装成功。窗口失焦的后台环境两个都会失败（这是浏览器的规矩，不是插件 bug）。
- 顶栏胶囊固定在 `top:6px; right:150px`，没有按窗口控件实测对齐；如果没有 `shell.overlay` 槽（个别环境），入口会退化成右下角的固定圆钮。
- 单机单文件，没有多端同步；profile 档只在本 profile 内共享。
- 没有提醒/定时：这不是提醒插件，是备忘录。
